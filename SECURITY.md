# Security policy

Cancerbero parses attacker-controlled model metadata. Please report suspected vulnerabilities privately to the security@cancerbero.dev rather than opening a public exploit issue.

A useful report includes the Cancerbero version, platform, minimal reproducer or malformed GGUF, observed impact, and whether the default non-executing path is affected. Remove private model content where possible.

Cancerbero is an inspection aid, not a security certification. Until a release is explicitly marked stable, pin the package version and knowledge-bundle digest used in automated policy.
